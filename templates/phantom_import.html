Phantom Import

Pulls .cine takes off a Phantom VEO into the download folder, the way the FTP import feeds footage from other cameras. Chataigne keeps control of record/stop; after each take it hands the camera to Glambot to save the clip, then takes it back. Point a project's footage source folder at the download folder.

// after you send "trig" and see "STR": POST {{ request.url_root }}phantom-import/take-complete body: {"partition": <n>} // before each "rec", and continuously: GET {{ request.url_root }}phantom-import/port-owner -> {"owner":"chataigne"} = safe to hold the Raw TCP socket / send rec/trig -> {"owner":"glambot"} = disconnect the Raw TCP module now, wait // optional: point "Show-control notify URL" above at a Chataigne OSC/HTTP // input that disconnects the module on "release" and reconnects on "resume".
